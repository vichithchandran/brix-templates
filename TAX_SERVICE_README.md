# Tax Service UI - Modern Design

A comprehensive, modern UI design for tax services focusing on GST and Income Tax. Built with Next.js, React, and Tailwind CSS.

## 🚀 Features

### 📊 **Hero Section**
- Eye-catching gradient background with animated elements
- Quick tax calculator widget
- Service highlights and statistics
- Call-to-action buttons

### 🏢 **GST Services**
- Complete GST service offerings
- Service cards with pricing
- Popular service highlighting
- Custom consultation options

### 💰 **Income Tax Services**
- Comprehensive tax solutions for individuals and businesses
- Tax slab comparison table (Old vs New regime)
- Step-by-step ITR filing process
- Category-based service organization

### ⭐ **Features & Benefits**
- Why choose us section
- Trust indicators and statistics
- 4-step process explanation
- Service guarantees

### 💬 **Client Testimonials**
- Real client feedback
- Service-specific testimonials
- Trust building elements
- Rating system

### 📞 **Consultation & Contact**
- Multiple contact methods
- Consultation packages
- Interactive contact form
- FAQ section
- Emergency support

## 🎨 **Design Elements**

- **Color Scheme**: Professional blues, purples, and gradients
- **Typography**: Multiple Google Fonts (Poppins, Montserrat, Open Sans, Monomaniac One)
- **Responsive Design**: Mobile-first approach with breakpoints
- **Animations**: Hover effects, transforms, and smooth transitions
- **Icons**: Emoji and SVG icons for visual appeal

## 📱 **Components**

1. `TaxHeader.jsx` - Navigation and branding
2. `TaxServiceHero.jsx` - Hero section with calculator
3. `GSTServices.jsx` - GST service offerings
4. `IncomeTaxServices.jsx` - Income tax solutions
5. `TaxFeatures.jsx` - Features and benefits
6. `TaxTestimonials.jsx` - Client testimonials
7. `TaxConsultation.jsx` - Contact and consultation
8. `Footer.jsx` - Website footer

## 🛠 **Tech Stack**

- **Framework**: Next.js 15.5.3
- **Library**: React 19.1.0
- **Styling**: Tailwind CSS 4.0
- **Fonts**: Google Fonts integration
- **Icons**: SVG and emoji icons

## 🌐 **Pages**

## 🚀 **Getting Started**

1. Install dependencies: `npm install`
2. Run development server: `npm run dev`  
3. Visit: `http://localhost:3000/tax-services`
4. Build for production: `npm run build`
