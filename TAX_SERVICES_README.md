# Tax Services Page

A modern, comprehensive tax service page designed for GST and Income Tax services. This page provides a complete solution for individuals and businesses looking for professional tax assistance.

## Features

### 🎯 Tax Service Hero Section
- Modern gradient background with floating animations
- Interactive tax calculator preview
- Key statistics and trust indicators
- Call-to-action buttons

### 💼 Service Offerings
- **GST Registration & Filing** - Complete GST compliance management
- **Income Tax Filing** - Professional ITR filing with maximum refund optimization
- **TDS Compliance** - TDS return filing and certificate generation
- **Tax Advisory** - Expert consultation and tax planning

### 🧮 Interactive Calculators
- **Income Tax Calculator** - Calculate tax liability for both new and old tax regimes
- **GST Calculator** - Determine GST registration requirements and liability
- Real-time calculations with instant results

### ✨ Key Benefits
- Expert tax professionals with 10+ years experience
- Maximum refund guarantee
- 100% compliance assurance
- 24/7 customer support
- Bank-level security
- Mobile app support

### 📋 Process Flow
1. **Document Collection** - Secure document upload
2. **Expert Review** - Professional document review
3. **Tax Optimization** - Maximize deductions and credits
4. **Filing & Submission** - Timely filing with confirmation
5. **Refund Tracking** - Real-time refund status updates

## Components

- `TaxServiceHero` - Hero section with calculator preview
- `TaxServices` - Service offerings grid
- `TaxCalculator` - Interactive tax calculators
- `TaxBenefits` - Key benefits and features
- `TaxProcess` - Step-by-step process flow
- `TaxCTA` - Call-to-action section

## Data Files

- `taxServices.json` - Service offerings data
- `taxBenefits.json` - Benefits and statistics
- `taxProcess.json` - Process steps data

## Usage

1. Navigate to `/tax-services` to view the complete tax services page
2. Use the interactive calculators to estimate tax liability
3. Explore different service offerings and pricing
4. Follow the process flow to understand how tax filing works

## Design Features

- **Modern UI/UX** - Clean, professional design with smooth animations
- **Responsive Design** - Optimized for all device sizes
- **Interactive Elements** - Calculators, hover effects, and animations
- **Trust Indicators** - Statistics, testimonials, and security features
- **Clear CTAs** - Strategic placement of call-to-action buttons

## Technology Stack

- Next.js 15.5.3
- React 19.1.0
- Tailwind CSS 4
- Custom animations and gradients

## Getting Started

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Visit `http://localhost:3000/tax-services`

The tax services page is now fully integrated into the main application and accessible through the navigation menu.
